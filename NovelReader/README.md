# 简阅 (NovelReader)

网络小说纯文字阅读器。输入小说的章节列表页或阅读页网址，只显示正文和基本排版，
底部提供上一章 / 目录 / 下一章。

## 工作方式

1. **抓取**（`WebFetcher`）：页面通过隐藏的 `WebView` 加载，这样 Cloudflare 之类的
   JavaScript 验证、Cookie 和前端渲染都与浏览器一致。第三方域名的请求和图片被拦截
   （常见 JS 库 CDN 除外），去掉广告并加快加载。加载后会：
   - 等待人机验证通过，需要人工点击时把 WebView 显示出来，完成后自动继续；
   - 自动点击「展開全部」之类的按钮加载完整章节列表；
   - 滚动到底部若干次，触发懒加载 / 无限滚动的正文块。
   对纯 JavaScript 的按钮（`href="javascript:"`），用「在页面里点击它、等待跳转或内容
   变化、再读取结果」的方式导航（`performAction`）。
2. **解析**（`PageParser`，基于 Jsoup，不针对特定站点）：
   - 目录页：找出章节链接最密集的容器，再按相同 URL 形状收集全页链接，
     多个容器按最小章号排序（避免「最新章节」块排在前面）；
   - 阅读页：取正文文字最多的块（多个懒加载块时取其父容器），按 `<br>` / `<p>` 分段，
     过滤广告与站点水印行，去掉正文开头重复的标题；
   - 繁体页面统一转成简体显示（`Chinese.kt`，单字映射表 3510 对，用 Python 库 zhconv 逐字生成，
     只保留 BMP 内的字符；标题、正文、目录章节名、按钮文字都会转换）；
   - 导航：按链接文字识别 上一章/下一章/上一頁/下一頁/目錄 及简繁变体。目标依次取
     真实 href、`data-href` 类属性、页面脚本中与当前 URL 形状相同的章节地址
     （如 `loadChapter('prev')` 里的常量）、`rel=prev/next`、常见 CMS 的 `bookinfo` 对象，
     最后才退化为点击动作。章内分页链接（下一頁）优先于章间链接（下一章）。
3. **阅读**：固定浅色纸张主题，不跟随系统夜间模式，也禁止省电模式的强制变暗。
   阅读页默认全屏（隐藏系统状态栏和 App 的上下工具栏，刘海区域也用纸色填充并留白）。
   正文按屏幕大小切成若干页，**左右滑动翻页**（前一页在左、后一页在右），页脚显示
   「章节名　当前页 / 总页数」。在本章最后一页继续往后滑，自动加载下一章并停在其第一页；
   在第一页往前滑，自动加载上一章并停在其最后一页（上一章若在网站上分成多个网页，会一直
   跳到最后一个网页）。点页面中间切换工具栏，点左侧四分之一上一页、右侧四分之一下一页。
   字号可调（重新分页并保持阅读进度），段落首行缩进两字、段间距约 0.4 行。
   顶栏「首页」图标一键回书架，「更多」菜单里有历史记录 / 刷新 / 在浏览器中打开。
   记住每一网页的阅读进度，目录页定位并高亮上次读到的章节。支持从浏览器「分享」网址到本应用。
4. **预取**：每渲染完一页，后台依次抓取「下一页」和「上一页」并缓存；上一页若是分成多个网页的
   章节，还会顺着它的「下一页」链接预取到该章末尾（最多 4 跳），因此向前滑落到上一章末尾也是即时的。
   下一页 / 上一页是真实链接时直接加载；是 JS 按钮时在隐藏 WebView 里点一次并缓存结果（WebView 会
   随之离开当前页，之后若要对原页面执行别的动作，`performAction` 会先把原页面重新加载回来）。
   抓取共用一个 WebView、串行执行；命中缓存的翻页从点击到渲染小于 1 ms，后台每页约 3 到 5 秒。

## 已验证站点

| 站点 | 特点 | 验证内容 |
|---|---|---|
| twkan.com | Cloudflare 验证；目录需点「展開全部」由 ajax 加载 | 418 章目录、正文、上一章/下一章/目录 |
| deqixs.cc | 正文 ajax 渲染并前端分页（每章 5 页）、懒加载块、按钮全是 JS | 正文、脚本中的上一章链接、JS 点击翻页、目录 |
| xwbxsw.net | 静态页、章内分页 `_2.html` | 正文、翻页、下一章、目录定位 |

## 构建与测试

```bash
export JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home
./gradlew testDebugUnitTest      # 用 twkan.com 真实页面快照验证解析器
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

测试数据在 `app/src/test/resources/`：twkan 目录页（已展开）与第二章、deqixs 第 402 章第 1 页
（渲染后 DOM）、xwbxsw 第 387 章第 1 页。

## 代码结构

```
app/src/main/java/com/xingang/novelreader/
├── MainActivity.kt     # 输入网址 / 最近阅读列表 / 接收分享 / 历史入口
├── HistoryActivity.kt  # 浏览历史（最近 100 条）
├── ReaderActivity.kt   # 目录与正文显示、横向翻页、跨章、全屏、字号、预取、历史栈
├── Paginator.kt        # 把章节文本按屏幕切页
├── PageAdapter.kt      # ViewPager2 的页面与"加载上/下一章"哨兵页
├── WebFetcher.kt       # WebView 抓取、验证处理、展开全部章节
├── PageParser.kt       # 通用页面解析
├── Page.kt             # 数据模型
├── Library.kt          # 最近阅读、阅读位置、字号
└── ChapterAdapter.kt   # 目录列表项
```
